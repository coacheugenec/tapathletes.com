# robots.txt for https://tapathletes.com
# TAP Athletes — youth & high-school baseball pitching academy, Rogers, Arkansas
#
# POSTURE: permissive. We WANT to be crawled, indexed, quoted, and cited —
# by classic search engines AND by AI answer engines. Being the source an
# LLM cites when a parent asks "where can my kid learn to pitch in NWA?"
# is a primary acquisition channel for us, not a threat.
#
# WHY AI BOTS ARE NAMED EXPLICITLY BELOW:
# robots.txt matching selects only the SINGLE most-specific user-agent group
# for a given crawler; a named group completely replaces the `*` group for
# that bot. So naming them is not redundant decoration — it is (a) an
# unambiguous, auditable statement of intent, and (b) protection against a
# future maintainer adding a blanket restriction to `*` and silently locking
# out the answer engines we depend on. If you add a Disallow below, add it to
# BOTH groups or you will create a split policy by accident.
#
# Rule of thumb for edits: the only things that belong in Disallow are gated
# assets and print/PDF source pages. Everything public stays crawlable.
#
# Last reviewed: 2026-08-13

User-agent: *

# The email-gated PDF itself. A PDF cannot carry a <meta name="robots"> tag,
# and GitHub Pages cannot set an X-Robots-Tag header, so robots.txt is the
# ONLY lever available for it.
Disallow: /foundations/TAP-Athletes-Foundations-Curriculum-Guide.pdf

# NOTE — /foundations/curriculum-guide is deliberately NOT disallowed here.
# That page already carries <meta name="robots" content="noindex, follow">,
# which is the stronger guarantee: a crawler must FETCH a page to see its
# noindex tag, so blocking it in robots.txt would prevent the exclusion we
# actually want and could still leave a bare URL-only entry in the index.
# Let crawlers fetch it and honour the noindex. The same curriculum content
# is free and crawlable at /foundations/curriculum — that is the page we
# want ranked and cited.
